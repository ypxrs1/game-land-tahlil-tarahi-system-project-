# معرفی کلی پروژه و کسب‌وکار
نام پیشنهادی کسب‌وکار: گیم‌لند | GameLand

نوع کسب‌وکار: فروشگاه تخصصی کنسول بازی و لوازم گیمینگ (حضوری + آنلاین)

توصیف کلی:

گیم‌لند یک فروشگاه تخصصی برای فروش کنسول‌های بازی (پلی‌استیشن ۵، ایکس‌باکس سری X/S، نینتندو سوییچ)، بازی‌های اورجینال، لوازم جانبی گیمینگ (دسته، هدست، کیبورد، موس، صندلی گیمینگ، مانیتور) و ارائه خدمات تعمیرات و خرید و فروش بازی‌های دست‌دوم است.

هدف پروژه، تحلیل و طراحی یک سیستم یکپارچه برای مدیریت فروش، موجودی انبار، مشتریان، سفارش‌های آنلاین و خدمات پس از فروش است تا فرایندهای سنتی و دستی فروشگاه به‌صورت سیستمی و دقیق انجام شود.
